## About

```
Cybersecurity Analyst and Security Engineer focused on offensive security,
AI-driven penetration testing, and the security of AI/LLM systems themselves.
```

I'm **Parth Raval** — a security engineer who breaks systems to make them stronger. My work sits at the intersection of **classical offensive security** and **AI security**: end-to-end VAPT across Web, API, Android, iOS, Windows and Linux, and red-teaming the new class of AI/LLM pipelines that are quietly entering production everywhere.

At **IappSecure** I contribute to an **autonomous, AI-driven penetration-testing system** — integrating AI agents with deep-instrumentation tooling (runtime + static + value-based analysis, object tracking) to surface vulnerabilities at scale. I also run dedicated **AI/LLM security testing**: prompt injection, jailbreaks, unsafe-output and data-leakage evaluation across agent workflows.

Alongside the security work I build the tooling around it — report-generation engines, headless audit pipelines, and custom Burp/Frida instrumentation — with a strong product-engineering bias toward automation over manual repetition.

- **Engineering mindset:** automate the boring, validate everything, ship copy-paste-ready output
- **AI/ML focus:** LLM red-teaming, prompt-injection defense, AI-pipeline threat modeling, agentic security tooling
- **Full-stack:** HTML / CSS / JavaScript front-ends; Node.js / TypeScript + React tooling; Python automation

**Open To** &nbsp;→&nbsp; Security Engineering · AI Red-Teaming · Offensive Security R&D · Bug Bounty Collaboration · Open-Source Security Tooling
